# Future Wall - แบ่งงาน (Mockup)

แผนรวมอยู่ที่ [future-wall-plan.md](./future-wall-plan.md) ไฟล์นี้บอกว่าแต่ละหน้าต้องทำอะไร และควรเริ่มอะไรก่อน

## สถานะตอนนี้

| หน้า           | Route  | ผู้ทำ | สถานะ                                                           |
| -------------- | ------ | ----- | --------------------------------------------------------------- |
| 1. ตอบคำถาม    | `/`    | -     | **มี mockup แล้ว** (`app/pages/index.vue`)                      |
| 2. แมพ / เมือง | `/map` | -     | **มี mockup แล้ว** (`app/pages/map.vue`, `app/components/Map/`) |

ยังไม่ทำในรอบนี้: ฐานข้อมูล/เรียลไทม์, หน้า admin, จอใหญ่ `/wall`

## รัน

```bash
pnpm install
pnpm dev
```

> ถ้า `pnpm` ฟ้อง version `12.3.4` ไม่เจอ ให้ตั้ง `npm_config_manage_package_manager_versions=false` ก่อนรัน

## สัญญาระหว่างสองหน้า (ห้ามเปลี่ยนโดยไม่บอกกัน)

หน้า 1 เขียน หน้า 2 อ่าน ผ่าน `useMe()` ([app/composables/useMe.ts](../app/composables/useMe.ts))

```ts
interface Player {
  id: string
  nickname: string
  avatarType: 'rocket' | 'spark' | 'wizard' | 'maker' | 'explorer' | 'star'
  answers: number[]
  createdAt: string
}
```

- หน้า 1 กดปุ่ม "ส่งห่านของฉันไปที่เมือง" → `navigateTo('/map')`
- หน้า 2 ใช้ `const me = useMe()` แล้วอ่าน `me.value` (เป็น `null` ได้ ถ้าเปิด `/map` ตรง ๆ ให้พากลับ `/`)
- ตอนนี้เก็บใน localStorage ของเครื่องเดียว เมื่อมี backend ค่อยเปลี่ยนไส้ใน `useMe` ผู้เรียกไม่ต้องแก้

ของที่ใช้ร่วมกัน: `app/types/index.ts`, `app/data/avatars.ts`, `app/components/GooseImg.vue` (แสดงห่านตาม `avatarType` และท่า `stand` / `walk` / `walk2`)

## หน้า 1 - ตอบคำถาม (`/`)

### ทำแล้วใน mockup

- [x] กรอกชื่อเล่นก่อนเริ่ม (ตรวจชื่อว่าง/ยาวเกิน/คำหยาบ)
- [x] ตอบทีละข้อ มีแถบความคืบหน้า
- [x] หน้าโหลดสั้น ๆ แล้วโชว์ผล: ห่านที่ได้ + ชื่อประเภท + คำอธิบาย
- [x] ปุ่มส่ง พาไปหน้าแชร์ `/share` (`app/pages/share.vue`) แล้วมีปุ่มไปหน้า 2 และปุ่มเล่นใหม่
- [x] หน้า `/share`: สร้างการ์ด 1080 x 1920 PNG ด้วย canvas (`app/utils/card.ts`) มีปุ่มดาวน์โหลด แชร์ไปแอปอื่น (Web Share API) และคัดลอกรูป
- [x] คำนวณผลจากคะแนน เสมอกันใช้ค่า hash ของชื่อ+คำตอบ (ได้ผลเดิมเสมอ)

### ลำดับที่ควรทำต่อ

1. **ใส่ชุดคำถามจริง** แทน placeholder ใน `app/data/questions.ts` (แต่ละตัวเลือกให้คะแนนกับ Avatar ตัวไหนบ้าง)
2. **ใส่ชื่อประเภท/ข้อความจริง** ใน `app/data/avatars.ts` และจำนวน Avatar สุดท้าย (ถ้าเปลี่ยนจำนวน ต้องแก้ `AvatarId` ใน `app/types/index.ts` ด้วย)
3. ใส่ภาพ Avatar จริง ใส่ไฟล์ใน `public/avatars/` แล้วกำหนด `images` ใน `avatars.ts` (สเปก: PNG พื้นใส สูง ~1024px หันขวา ไม่มีเงา ไม่มีข้อความ ท่า `walk` ต้องมี `stand` / `walk2` / `prop` ถ้ามี)
4. ปรับ UI ให้ตรงดีไซน์จริง + ข้อความแจ้ง PDPA
5. ทดสอบบนมือถือจริง (iOS Safari / Android Chrome / เบราว์เซอร์ใน LINE และ IG) โดยเฉพาะปุ่มแชร์และดาวน์โหลด ซึ่งเบราว์เซอร์ในแอปบางตัวไม่รองรับ (มีข้อความให้กดค้างที่รูปเพื่อบันทึกแทน)
6. ยืนยันโลโก้และข้อความท้ายการ์ดใน `app/utils/card.ts` (ตอนนี้เป็นข้อความชั่วคราว) และลิงก์เว็บในข้อความแชร์ ให้ตรงกับโดเมนจริง

### ที่ยังไม่ทำ (ทำทีหลัง)

- บันทึกผู้เล่นขึ้นเซิร์ฟเวอร์ (แผนคือ Supabase) เพื่อให้จอใหญ่เห็นคนจากหลายเครื่อง
- รายการคำต้องห้ามใน `app/data/blockedWords.ts` เป็นแค่ชุดเริ่มต้น ต้องเติมก่อนวันงาน (`blockedSubstrings` ห้ามปรากฏในชื่อ, `blockedExactWords` ห้ามเป็นคำทั้งคำเท่านั้น เหมาะกับคำสั้นที่ซ้อนกับชื่อปกติได้) ตรวจแค่ฝั่งเบราว์เซอร์ ถ้ามี backend ต้องตรวจซ้ำฝั่งเซิร์ฟเวอร์ด้วย

## หน้า 2 - แมพ / เมือง (`/map`)

### ทำแล้วใน mockup

- [x] ฉากเมือง (`MapScene.vue`) และขอบเขตที่เดินได้
- [x] ห่านของผู้เล่นตกลงมาแล้วเด้ง มีชื่อเล่นลอยเหนือหัว (ป้ายสีเหลือง)
- [x] เดินสุ่ม หยุดพักด้วยท่า `stand` พลิกซ้ายขวา สลับ `walk`/`walk2` เด้งขึ้นลง ย่อขยายตามความลึก
- [x] ห่านตัวอย่าง 4 ตัว (ปรับ `demoNpcCount` ใน `map.vue`)
- [x] จอ stage 1080 x 1920 ย่อให้พอดีทุกขนาดหน้าจอ
- [ ] ยังไม่ทดสอบบนจอ Kiosk จริง และยังเป็นผู้เล่นคนเดียว (ไม่มีหลายคน/คิว Spotlight)

### สิ่งที่ต้องได้

1. เปิดหน้าแล้วเห็น **พื้นที่แมพ** (ฉากเมือง/พื้นที่ให้ห่านเดิน)
2. ห่านของผู้เล่น (`useMe()`) **สปอนลงมาในแมพ** มีแอนิเมชันตอนลงมา (เช่น ตกลงมาแล้วเด้ง) พร้อมชื่อเล่นลอยเหนือหัว
3. ห่าน **เดินเล็ก ๆ น้อย ๆ แบบสุ่ม** ไปมา: สุ่มทิศ, หยุดพักด้วยท่า `stand` เป็นระยะ, พลิกภาพซ้ายขวาตามทิศเดิน (ภาพต้นฉบับหันขวา), ท่า `walk` กับ `walk2` สลับกันให้ดูก้าวขา, เด้งขึ้นลงเล็กน้อย
4. ห่านอยู่ในขอบเขตแมพ ไม่เดินออกนอกจอ
5. (ถ้ามีเวลา) ย่อ/ขยายตามความลึก (ยิ่งอยู่ล่างจอยิ่งใหญ่) ให้ดูเป็น 2.5D และซ้อนทับตามลำดับ y

### ลำดับที่ควรทำ

1. ทำฉากแมพนิ่ง ๆ ก่อน (พื้นหลัง + ขอบเขตที่เดินได้)
2. สปอนห่านของ `me` ลงมา + แอนิเมชันตก
3. ทำการเดินสุ่ม (ลูป `requestAnimationFrame` หรือ `useRafFn` จาก VueUse) แก้ตำแหน่งผ่าน `transform` โดยตรง ไม่ต้องให้ Vue re-render ทุกเฟรม
4. ท่าเดิน/ท่ายืน/พลิกทิศ/เด้ง
5. ใส่ห่านตัวอย่างอื่นอีกไม่กี่ตัวให้เห็นบรรยากาศ (ไม่บังคับ ใช้ค่าคงที่เปิด/ปิดได้ง่าย)
6. จัดเลย์เอาต์สำหรับจอแนวตั้ง 1080×1920 (ดูสัดส่วนในแผนรวม หัวจอ ~10% / Spotlight ~45% / Wall ~35% / ท้ายจอ ~10%) ถ้าจะใช้เป็นจอใหญ่

### ข้อควรรู้

- จอจริงคือ Kiosk 43" ทัชสกรีน 1920 × 1080 หมุนเป็นแนวตั้ง (Windows 11, Core i5 Gen 6, RAM 8GB) ดูรายละเอียดใน [future-wall-plan.md](./future-wall-plan.md) หัวข้อ 6.1 ทำแอนิเมชันให้เบาและกันการแตะที่ไม่ตั้งใจ

- ห่านตอนนี้เป็นภาพ SVG placeholder สร้างโดย `app/utils/goose.ts` ใช้ผ่าน `<GooseImg :type="..." pose="walk" />` เมื่อมีภาพจริงจะสลับให้เองโดยไม่ต้องแก้หน้า 2
- เป้าหมายรวมของจอใหญ่ในอนาคต: หลายคนพร้อมกัน, ต่อคิว Spotlight, จำกัดไม่เกิน ~40 ตัว ในรอบ mockup นี้ทำแค่ผู้เล่นคนเดียวก็พอ
